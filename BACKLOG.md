# Backlog — the shared work board

## How to use it

- Read this board before starting; Kevin's directives rank first, then the highest unclaimed Ready item.
- Claim work in In progress with your name and date, commit the claim immediately, and coordinate shared files in the office.
- Keep items to a bold title and at most one evidence line; put detail in project documentation.
- Record newly found work in Ready or Icebox. Move only your own claims; preserve peer entries.
- Done requires committed, pushed work and evidence exercising the result; deployed work also needs live proof. Otherwise use Shipped, awaiting live proof.
- Keep the newest 20 Done entries. Commit and push board changes with the work; never force-push main or skip hooks.
